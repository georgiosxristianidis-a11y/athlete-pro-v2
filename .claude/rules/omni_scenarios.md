# OMNI AGENTS: PROTOCOL & SCENARIO ADHERENCE

> **Статус:** Обязательный профессиональный контракт для всех мультиагентных исполнителей (Claude Code, Gemini Pro, Antigravity, Omni/Subagents).
> **Принцип:** Никакой самодеятельности и галлюцинаций — строгое следование детерминированным сценариям, дизайн-токенам и контрактам состояний.

---

## 1. 🎯 [SCENARIO_DISCIPLINE] — Железные правила следования сценариям

### 1.1. Закон Единой Цели (Single Goal Constraint)
- **1 Сессия = 1 Задача = 1 Сценарий.** Запрещено смешивать несколько фич, миграций и рефакторингов в одной сессии.
- Агент обязан начинать работу только после фиксации триады:
  ```yaml
  ЦЕЛЬ: Конкретный результат (1 предложение).
  ГДЕ СТОП: Четкие критерии Definition of Done (DoD) и файлы границы.
  НЕ ТРОГАТЬ: Защищенные модули, формулы и внешние файлы.
  ```
- **Запрет выхода за границу:** Агенту категорически запрещено модифицировать файлы вне списка `ГДЕ СТОП`.

### 1.2. Контрактное выполнение (Contract-First Execution)
- Все переходы между экранами, модалками и состояниями маскота строятся на **детерминированных конечных автоматах (FSM)**.
- Запрещено добавлять промежуточные состояния, реплики или кнопки, не зафиксированные в утвержденном сценарии или `docs/handoff/`.
- Если сценарий требует развилки — агент обязан применить протокол **«Рекомендация, а не меню»**: предложить лучший вариант с обоснованием в 1 строку и дождаться выбора человека.

## 2. 🐼 [PANDA_CORE_BIBLE] — Сценарный кодекс маскота

Каждый агент, работающий с Panda Core, FAB или диалогами ассистента, обязан соблюдать каноны персонажа:

| Параметр | Правило | Нарушение |
| :--- | :--- | :--- |
| **Лимит реплики** | **Строго ≤ 5 слов** (`TALK_MAX_WORDS = 5`). Лаконичный, острый, ироничный тон. | Длинные рассуждения, вежливая вода. |
| **Системные эмодзи** | **ЗАПРЕЩЕНЫ в UI.** Только кастомные SVG-иконки или чистый текст. | Использование стандартных Unicode эмодзи (🔥, 🐼, 💪). |
| **Матрица мимики (Moods)** | Строго 4 базовых состояния: `idle`, `chew`, `cheer`, `judge` + временные контексты (`night_shift`, `early_bird`). | Выдумывание новых состояний без правки FSM. |
| **Режим `judge` (Осуждение)** | **Полная тишина (`SILENT_MOODS`).** Никакого звука и длинных тирад — только deadpan-взгляд и тряска `.shake-once`. | Звуковые эффекты или оправдания на переборе отдыха. |
| **Синхронизация волны (`.talk-wave`)** | Длительность реплики = чистая функция `talkDurationMs(mood, text)` (420мс/слово, пол 700мс). | Рандомные таймеры или визуальный шум без привязки к тексту. |
| **Звуковой бюджет (PANDA-C)** | Формат `.m4a` (AAC), моно, 48 кбит/с, суммарно ≤40 КБ. Звук **только на смене мимики** (не фоновый луп). | Несжатые WAV/MP3, бесконечный хруст. |

## 3. 🛡️ [VERIFY_OVER_TRUST] — Протокол валидации и гейтов

1. **Запрет слепого доверия:** Любое заявление агента («всё готово», «ошибок нет») считается **гипотезой**, пока машинный гейт не вернет код `0`.
2. **Обязательный запуск тестов:**
   ```bash
   npm test               # Unit + Integration тесты
   npm run preflight      # Комплексная проверка репозитория и веток
   ```
3. **Хирургическая проверка рендеринга:**
   - Для UI/шейдеров/графики агент обязан верифицировать результат через скриншоты Playwright (`headless: true`) с проверкой `gl.getError() == 0` и отсутствием черных экранов / битых текстур.
4. **Защита медиа-бюджета (F-7 Guard):**
   - Медиа-файлы не должны раздувать pre-cache Service Worker (лимит 1.5 МБ). При добавлении ассетов обязателен прогон `npm run build:sw`.

## 4. 🔀 [MULTI_AGENT_ISOLATION] — Изоляция и передача контекста

- **Работа только в Worktree / изолированных ветках:** Прямой коммит в `main` заблокирован. Слияние выполняет только LEAD-агент через PR после прохождения всех проверок.
- **Микро-хендоффы (docs/handoff/):** По завершении фазы агент создает/обновляет компактный файл хендоффа (20–40 строк), фиксируя:
  - Что реально сделано и протестировано (с прикреплением фактов/логов).
  - Точный остаток для следующей сессии.
  - Уроки и ловушки кода (Lessons Learned).
