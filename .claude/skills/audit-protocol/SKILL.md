# Протокол аудита и трата Fable

> Решение Gio 12.11.2026. Аудит начинается с карты покрытия, а не с осей.

## Роли

- **Fable (LEAD)** — три работы: создаёт (код, дизайн, моторика), рефакторит, ищет слабые места — уязвимости и дыры в безопасности, в логике продукта, в дизайне и движении. Плюс суждение: живые скрины, приоритеты, карточки, ревью на поломку.
- **Не Fable** — инвентарь: грепы, обход CSSOM, списки keyframes, таблицы слоёв. Дешёвые субагенты параллельно по осям; в контекст LEAD возвращается только таблица, не выдержки кода.

## Конвейер

0. **Карта покрытия — до осей.** Хендоффы в `docs/handoff/`, открытые PR, живые сессии: что уже аудировано. Покрытое идёт в НЕ ТРОГАТЬ и называется Gio. 12.11 из четырёх запрошенных осей три уже были разобраны другими линиями.
1. **Рамка.** Один вопрос, эталон (`.claude/rules/design.md`, `.claude/rules/security.md`), границы. Аудит только читает: находка не равна правке.
2. **Инвентарь.** Субагенты, таблицы.
3. **Живой прогон.** 375 px, обе темы, по слоям — оверлеи отдельным проходом; перекрытие судится попаданием (`elementFromPoint`), не чтением CSS. Каждой находке доказательство: скрин, `file:line` или замер.
4. **Синтез.** Тяжесть: P0 — теряются данные, дыра эксплуатируема или задачу не довести; P1 — трение на каждом проходе; P2 — редкий путь; P3 — полировка. Размер S/M/L. Не больше 12 карточек, по отношению пользы к цене. Число — с нормой и «почему».
5. **`/devil` на отчёт** до коммита.
6. **Решает Gio.** Карточка = PR = сессия. Одна ось — одна сессия.

## Линзы по доменам

| Домен | Что ищем | Опора |
|---|---|---|
| Безопасность | дыра, которую можно эксплуатировать; гард, который зеленеет, не проверяя | `/audit_cyber`, `.claude/rules/security.md` |
| Продукт | тапы до цели, тупики, потеря введённого, цель касания меньше 48 px, состояния пусто / ошибка / офлайн | сценарии, живой прогон |
| Моторика | paint каждый кадр, бесконечные анимации, нет reduced-motion, хост пересоздаётся рендером | фильтр отбора в `docs/handoff/HANDOFF_motion_pro.md`; замер кадров раньше суждения |

## Правка по находке

- Сперва воспроизвести: baseline обязан показать баг. Потом чинить.
- Гард к фиксу прогнать на поломку: без фикса — красный.
- Риск — за флагом `js/flags.js`, дефолт OFF.
- Образец карточки аудита — UX-1 (`docs/handoff/HANDOFF_ux_mechanics_audit.md`, если влит).
