## 1. 🔬 Аудит Логики и Механики (Bottlenecks & Weak Spots)

Приложение уже находится в топ-1% по меркам производительности (Lighthouse 95-100). Архитектура (Store/View, Vanilla JS, IndexedDB) обеспечивает железобетонную надежность оффлайн-работы. Однако, при переходе в "Elite" сегмент, всплывают следующие узкие места:

### Уязвимости и Слабые Места (Threats & Bottlenecks)
1. **Риск Prototype Pollution (Угроза из THREAT_MODEL)**: Текущая защита держится на числовых индексах и структурах `Map`. Если в будущем будет добавлен рекурсивный `deep-merge` (например, при сложной облачной синхронизации), система может стать уязвимой. Это бомба замедленного действия.
2. **Отсутствие Build Pipeline для Минификации**: Проект отдаёт ~600 КБ неминифицированного JS и 86 КБ CSS (часть из которого unused на первом экране). На мощных устройствах это незаметно, но на 3G-сетях или старых смартфонах это вызывает задержки FCP/LCP.
3. **Хрупкость AI-Парсера (`intel.view.js`)**: Извлечение JSON-виджетов (readiness) и Markdown-разметки из потокового ответа (SSE) работает на регулярных выражениях (`/\{[\s\S]*"_widget"/`). При изменении структуры ответа от Gemini/Claude это сломается. 
4. **Конкуренция за Main Thread при Старте**: 34 тега `modulepreload`. Это "забивает" канал сети и парсер браузера, откладывая отрисовку критического CSS.
5. **Background Заморозка (iOS/Safari)**: Rest-таймер переведён на `setInterval` + catchup, но Document PiP и фоновые процессы всё ещё страдают от агрессивного троттлинга Safari при сворачивании приложения.

## 2. 💎 Стратегия Бренд-Продвижения (Elite Tier)

Athlete Pro не должен конкурировать с бесплатными дневниками тренировок. Это **Premium AI-Companion**.

1. **"Air & Minimalism" как ДНК Бренда**: Продвигать интерфейс без визуального шума. Пользователь платит за *фокус*. Маркетинг должен строиться вокруг "отсутствия отвлекающих факторов", "идеального черного", "неоновых акцентов" и 60fps анимаций (Apple-like feel).
2. **P.A.N.D.A. Core (Neural Command Center)**: Упаковка AI. Не просто "чат-бот", а "аналитический центр". Озвучка TTS, тепловые карты мышц (Heatmap), индекс готовности (CNS Readiness). Это killer-feature для продвижения в соцсетях (Instagram/TikTok Reels с озвучкой коуча).
3. **Privacy First (Airgap / Anon)**: Элитная аудитория ценит приватность. Подчеркивать, что данные шифруются (AES-256-GCM) и лежат на устройстве (Offline-first), а не продаются дата-брокерам.
4. **Ощущение премиальности (Haptics & Motion)**: Микро-вибрации (haptic feedback) при завершении сета, физика пружин (Spring Physics) при смайпе модалок — это нужно показывать на демо-видео. Это создает разницу между "веб-сайтом" и "нативным премиум-приложением".

## 3. 📋 План Фаз и Делегирование (OPUS 5 / Sonnet 5)

Вся работа строго делится по ролям. **OPUS 5** забирает архитектурные риски и безопасность. **Sonnet 5** полирует компоненты, парсеры и UI-логику.

### ФАЗА 1: Performance Foundation (Критическая Скорость)
*Цель: Lighthouse 100/100, FCP < 1.0s.*
- [ ] **S5 (Sonnet 5)**: *Modulepreload Pruning*. Оставить только 5 критических модулей в `index.html`. Остальные 29 грузятся лениво.
- [ ] **S5 (Sonnet 5)**: *Critical CSS Preload*. Добавить `<link rel="preload" as="style">` для `base.css` и `dashboard.css`.
- [ ] **O5 (OPUS 5)**: *Zero-config Minifier*. Внедрить легковесный `esbuild` скрипт в `scripts/build-sw.mjs` для сжатия CSS/JS на лету перед деплоем, не ломая Vanilla-опыт разработки.

### ФАЗА 2: Resilience & Security (Неуязвимость)
*Цель: Устранение потенциальных векторов атак и крашей.*
- [ ] **O5 (OPUS 5)**: *AST/Deep-Merge Guard*. Написать жесткий `Object.freeze` / `proto` guard для любых будущих операций слияния данных, закрывая риск Prototype Pollution из Threat Model.
- [ ] **O5 (OPUS 5)**: *Stream Parser Refactor*. Переписать парсинг потока в `intel.view.js` с хрупких Regex на надежный стейт-машинный (FSM) буфер. Разделить поток на "Текст для TTS" и "Метаданные виджетов" без шансов на обрыв JSON.
- [ ] **S5 (Sonnet 5)**: *Error Boundary UI*. Если падает виджет AI, падать должен только виджет, а не весь экран P.A.N.D.A. Core.

### ФАЗА 3: Elite UX & Background Sync (Магия)
*Цель: Ощущение нативного приложения.*
- [ ] **O5 (OPUS 5)**: *Wake-Lock API Integration*. Внедрить надежный перехват экрана (screen wake lock) во время тренировки с авто-возобновлением при `visibilitychange`.
- [ ] **S5 (Sonnet 5)**: *Advanced Haptics*. Провести аудит вибро-откликов. Добавить различающиеся паттерны (легкий тап для галочки, тяжелый двойной для рекорда 1RM).
- [ ] **S5 (Sonnet 5)**: *Offline-Sync Resync Queue*. Усилить IndexedDB очередь для бесшовной синхронизации при обрывах связи в зале (подвальные помещения).

### ФАЗА 4: Marketing & Analytics (Бренд)
*Цель: Генерация контента для шаринга.*
- [ ] **S5 (Sonnet 5)**: *Heatmap Share Image*. Сделать генерацию картинки (canvas-to-blob) "Моя готовность ЦНС / Heatmap" для шеринга в соцсети одним тапом (Web Share API).
- [ ] **O5 (OPUS 5)**: *Voice-First Interface*. Расширить интеграцию TTS — разрешить коучу короткие аудио-нотификации в фоновом режиме через Web Audio API (например: "Отдых окончен. Подход 3. Вес 100 килограмм").
