## SEO-2 — og:image 1200x630 вместо квадратной иконки

**ЦЕЛЬ.** `og:image`/`twitter:image` отдают `icons/icon-512.png` — 512x512 при
`twitter:card=summary_large_image`. Соцсети под баннер 1.91:1 квадрат кропят по центру или
роняют карточку до `summary`. Нужна честная превьюшка 1200x630.

**ГДЕ СТОП.** В `index.html` `og:image`/`twitter:image` указывают на файл 1200x630 с
абсолютным URL, `og:image:width`/`height` совпадают с реальными пикселями, `npm test`
зелёный (в первую очередь `test/sw-media-budget.test.js`), картинка не в прекеше.

**НЕ ТРОГАТЬ.** Тексты мета (длины уже в коридорах), ландмарки, аватар, `theme-boot.js`.

### Как делать

1. **Сгенерить PNG 1200x630.** Sharp/ImageMagick в проекте нет, зато есть Playwright —
   отрисовать HTML-макет (лого + вордмарк на `--c-bg`, палитра из `css/base.css`) и снять
   `page.screenshot`. Скрипт генерации — одноразовый, **не коммитить** (закон структуры,
   `test/repo-hygiene.test.js`); в репо едет только PNG.
2. **Держать вне прекеша.** `icons/` целиком сканируется в `scripts/build-sw.mjs`
   (`dirsToScan`), а запас бюджета исчерпан: потолок 1.55 МБ, после SEO-1 занято ~1.55.
   Соцбот тянет картинку сам, из UI её никто не запрашивает — место ей рядом с
   `INSTALL_ICON_RE`, куда SEO-1 уже выселила `apple-touch-icon`. Либо отдельным правилом
   `OG_IMAGE_RE`, чтобы смысл исключения читался.
3. **Пересобрать SW** — `npm run build:sw`, руками `ASSETS` не трогать.
4. **Проверить в поле.** Превью не увидишь локально: боты ходят на прод. После мёржа —
   валидатор карточек X и `curl -sI` на файл (200 + `image/png`).

### Грабли

- **Прекеш стоит вплотную к потолку.** Любой байт в `index.html`, `css/`, `js/` теперь может
  уронить `test/sw-media-budget.test.js`. Сообщение теста врёт про «budget is 1.50 MB» —
  константа `PRECACHE_BUDGET_BYTES` = 1.55 МиБ. Потолок не поднимать: F-7 про мобильный
  трафик установки, а не про удобство.
- **Кеш соцсетей.** X и Facebook кешируют превью надолго; после выката гнать через их
  дебаггеры, иначе «не изменилось» — это кеш бота, а не твоя ошибка.
- **Эмодзи в макете запрещены** — только SVG (DESIGN_DNA).
