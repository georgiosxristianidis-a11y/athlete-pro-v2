### ORBIT-1 — орбита умного отдыха

**Идея.** Внешнее кольцо — таймер отдыха, внутреннее ядро бьётся в такт сердцу; пульс остыл
до порога — замок щёлкает «ГОТОВ».

**Вход (блокер) — источник пульса.**

- **A (рек.) — нагрудный пояс через Web Bluetooth в PWA.** Android Chrome умеет, Capacitor не
  нужен; стандартный Heart Rate Service отдаёт и HR, и R-R.
- **B — Galaxy Watch.** Стандартный пульс по BLE часы не отдают: нужно своё Wear-приложение и
  Capacitor-мост (план TONNAGE T08–T11) плюс партнёрство Samsung Sensor SDK.

**ЦЕЛЬ.** Кольцо поверх нынешней модели таймера, ядро пульсирует по **реальным** R-R, порог
«готов» — по восстановлению пульса (порог выводится из данных, не выдумывается).

**НЕ ТРОГАТЬ.** Модель `js/rest-timer.js`: `setInterval` 1 Гц от абсолютного времени — rAF мёртв
при погашенном экране, это осознанно. Без датчика ядро **не пульсирует**: фальшивый ритм —
враньё, против бренда; без пульса остаётся обычное кольцо таймера.
