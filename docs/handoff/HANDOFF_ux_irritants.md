## Карточки по приоритету

### P1 — сбои и неверные числа

- **UX-2a (P1, S, Sonnet) — экран не гаснет.** ЦЕЛЬ: блокировка держится всю тренировку. Повторный запрос на
  `visibilitychange` → visible при живой сессии и `keep-awake` ON; запрос при восстановлении сессии; тумблер
  в профиле берёт и отпускает сразу. ГЕЙТ: юнит с подменой `navigator.wakeLock`. ГДЕ СТОП: код и тест; поле — Gio
  (Android, экран 30 с). НЕ ТРОГАТЬ: таймер отдыха, PiP.
- **UX-2b (P1, S, Sonnet) — «+15 с».** Сперва воспроизвести в превью 375×812 (тап через `elementFromPoint`,
  край кнопки). Причина найдена → фикс: зона тапа внутри острова, цифра обновляется сразу, хаптика 8 мс.
  ГДЕ СТОП: не воспроизвелось → отчёт с замерами, поле Gio. НЕ ТРОГАТЬ: долгое нажатие (настройки), режим
  `rest-island-count`. Соседи: UX-1e, UX-1j (цели касания) — не сливать.
- **UX-2c (P1, S, Sonnet) — тренажёрный присед в статистике.** `Hack Squat` в имена записи реестра `squat.machine`
  (тест: каталог ⊂ реестр — каждое имя каталога резолвится). Подпись варианта «тренажёр» уже есть в реестре —
  это и есть пометка «machine». В DOTS не входит (решение 01.11). ГДЕ СТОП: код + тест; дальше нужны флаги ON (развилка 3).
- **UX-2d (P1, S, LEAD) — жим за 3 года.** Диагноз до кода: на экспорте Gio (локально, в репо не класть)
  выписать имена жима по годам и в какие кривые они падают при `stats-families` OFF и ON. Если гипотеза
  подтвердится — лечится флагом и, при нужде, строкой реестра. ГДЕ СТОП: отчёт с числами до правки.
- **UX-2e (P1, S, Sonnet) — материя без фриза.** Перерисовка только при смене ширины (высоту игнорировать);
  перерисовка не перезапускает циклы — продолжать с `currentTime`. Замирание через 12 с — замысел HOME-3, не
  трогать. ГЕЙТ: тест на RO (смена высоты не зовёт `paint`). Флаг `home-matter`.

### P2 — механика

- **UX-2f (P2, M, LEAD) — общий лист.** `js/shared/sheet.js`: свайп вниз за ручку и шапку (порог 80 px или
  скорость), тап по фону, въезд/выезд `sd-overlay`; подключать листы по одному. Мина: UX-1f («назад»
  закрывает лист) ходит через те же `registerOverlay`/`history.back()` — делать после UX-1f или одной сессией.
  `touch-action` на WebKit убивает жест (память) — e2e в webkit обязателен. За флагом `sheet-gestures`.
- **UX-2g (P2, S, Sonnet) — английские пары реестра.** `familyEn`/`variantEn`/`MUSCLE_EN` + один помощник
  подписи через `isRu()`; три места из карты. ГЕЙТ: тест «в EN нет кириллицы» на трёх рендерах. Соседи: ANL-A7
  (обратная сторона), `Session restored` — в UX-1h.
- **UX-2h (P2, M, LEAD, флаг) — период 1/3/6/12 мес.** Один сегмент-переключатель (паттерн 7/30/90 с Главной,
  `sparkline.js:10`) для объёма и индекса силы; объём: недели для 1/3 мес, месяцы для 6/12. Делать **сразу после
  ANL-A3** (тот же график: календарные недели, токены) — иначе двойная переделка `_renderVolumeChart`. Пункт «Год» из
  ANL-A4 закрывается здесь.
- **UX-2i (P2, M, LEAD, флаг) — время в зале.** Карточка Stats: среднее и сумма за неделю/месяц, тот же
  переключатель UX-2h (неделя, 1/3/6/12 мес). Импорт без длительности не считать и подписать «с N даты». Мокап до кода.
- **UX-2j (P2, S, Sonnet) — скрытая Лаборатория.** После развилки 2: Лаборатория уходит из Профиля в лист,
  открываемый жестом по версии; переустановка SW — кнопкой внутри; «Снаряды» (`gym-equipment`) — туда же,
  свёрнуто. ГЕЙТ: тест жеста; Лаборатория недостижима без жеста. НЕ ТРОГАТЬ: сами флаги и их дефолты.
- **UX-2k (P2, S, Sonnet) — цельные кривые.** Один монотонный сплайн через все точки, без моста-пунктира и
  точек-одиночек; разрыв > N мес — тихая метка на оси, не излом. Проверить `preserveAspectRatio="none"`.
  Соседи по файлу: ANL-A6, ANL-A8 — по очереди.

### P3 — вид (сперва мокап «было / A / B», решает Gio, код — Sonnet)

- **UX-2l (P3, S, LEAD→Sonnet) — сводка недели.** Инлайн-стили → классы; «Спросить коуча» — `.btn-ghost`
  во всю ширину, «Закрыть» — крестик в шапке или `.btn-text`; воздух по шкале `--sp-*`. Свайп — из UX-2f.
- **UX-2m (P3, S, LEAD→Sonnet) — календарь.** Развилка 1.
- **UX-2n (P3, S, LEAD→Sonnet) — карточка «Сегодня».** «ещё N упр.» открывает список плана (баг — можно
  раньше мокапа отдельным S); текст: тип, 1 упражнение, CTA. Соседи: HOME-1/2/3 — флаг `home-feed-a`.
- **UX-2o (P3, S, LEAD→Sonnet) — без лишнего зелёного.** Активный период и свой диапазон — нейтральное
  стекло (hairline + `--c-text`), не `--c-accent`; зелёный остаётся только у Push. Смотреть с ANL-A3/A5.
- **UX-2p (P3, S, LEAD→Sonnet) — номер упражнения.** Тонкое кольцо или скруглённый квадрат цвета дня PPL с
  мягким `--glow-*`, цифра шрифтом и кеглем пилюли POWER/SHAPE (`chamber-pill.js`); мёртвые правила pull/legs убрать.
