> Карточка = PR = бамп версии.

## Числа с нормой

- **Первый подход с пустой базы:** 5 тапов и один длинный жест: 60 кг = 24 деления барабана, 864 px через
  окно 72 px. Норма журналов тренировок — число вводится тапом, следующий подход наследует вес.
- **Обычный подход со второй сессии:** 1 тап, если подставленный вес подошёл. Это хорошо.
- **Цель касания:** Android просит 48 dp, проект по факту держит 44 (`workout.css:675`). Ниже обеих норм:
  блины и меню упражнения 32, «+15»/«пропустить» в острове 28x26, чипы RPE 27, «−/+» редактора 28.
