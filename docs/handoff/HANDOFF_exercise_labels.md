# HANDOFF — Русские имена упражнений

> Заведён 2026-08-30 решением Gio. Узкая линия рядом с треком запуска — не блокер
> раздачи ссылки. База: только `origin/main`. Ритуал ветки — скилл `agent-brief`.
> «Влито» = ancestry в `origin/main`, не «PR создан».

## Почему так, а не «перевести план»

Интерфейс на `ru` уже через `t()`. Имена упражнений — нет: на экране `Bench Press`,
хотя в `exercises-library.json` у той же записи лежит `nameRu: "Жим штанги лёжа"`.

Канон — английский `ex.name`. Он же ключ истории, 1RM и плана. 2026-07-08 переименование
лифтов в пресете оторвало веса: поиск шёл по точному `ex.name`, всё стартовало с 0 кг.
После этого имя — идентификатор, не подпись. `alias` — для старых имён, `tag` — только
для острова. Оба не для перевода.

`nameRu` в рантайме почти мёртв. Живой только в `isBodyweightExercise`
(`js/workout.store.js`) — сверка обоих имён, чтобы BW-тоггл не промахнулся. Показ
везде `esc(ex.name)`: пикер (`js/workout.view/modals.js:580`, `:755`), карточка
тренировки (`js/workout.view/render.js:458`). Поиск пикера смотрит `name` + английские
tags/muscles, запрос «жим» пустой.

Пресет `PPL_GIO_PLAN` пишется по-английски (`Bench Press`, не `Barbell Bench Press`).
Новичок получает эти строки в план. Слой показа обязан резолвить сид в библиотеку,
как уже делает `resolveMuscleGroup` (бидирекционный substring + таблица оверрайдов).
Иначе карточка зелёная на пикере и красная на первой тренировке.

## EX-RU-1 · Показ nameRu: хелпер, пикер, список тренировки

- **ЦЕЛЬ.** При `lang=ru` человек видит русские имена в пикере упражнений и в списке
  активной тренировки. В плане, журнале и 1RM по-прежнему лежит английский `ex.name`.
- **ГДЕ СТОП.** Чистый профиль, язык RU. Пикер: «Жим штанги лёжа», поиск «жим» находит.
  Тап пишет в план английский `name` (как сейчас `dataset.name = ex.name`). Старт дня
  из `PPL_GIO_PLAN`: карточки списка — русские, не `Bench Press`. Кастом без `nameRu`
  остаётся как ввели. Переключатель на EN возвращает английские подписи, данные те же.
- **ФАЙЛЫ:** `js/shared/exercise-label.js` (новый, чистый) · `js/workout.view/modals.js`
  (пикер add + replace: показ и поиск) · `js/workout.view/render.js` (`renderExerciseCard`)
  · `test/exercise-label.test.js` (новый) · `js/version.js` + `package.json` + lock.
  `sw.js` — только через `npm run build:sw`.
- **ГЕЙТ:** `npm run preflight && npm run build:sw && npm test && npm run lint`.
  Цепочку прогнать на свежем `origin/main` до выдачи (AGENT-7).
- **НЕ ТРОГАТЬ.** Миграцию данных: не переписывать `ex.name` в плане, сессии, IDB, 1RM,
  бэкапе, CSV/TXT. Поле имени в редакторе плана (`wo:planName`) — это идентификатор,
  туда `nameRu` нельзя: сохранение оторвёт историю. Журнал, остров, сводка, аналитика,
  дом, intel — следующая карточка, не этот заход. Строки `nameRu` в JSON библиотеки
  уже есть, библиотеку не переводить заново. `alias` / `tag` / `MUSCLE_GROUP_OVERRIDES`.
  PC-2, LAUNCH-10, F-7/F-8.

### Как делать

1. **Хелпер чистый, без стора.** `exerciseLabel(name, { library, lang })` и
   `findLibraryExercise(name, library)`. `exercise-label.js` не импортирует
   `workout.store.js` — цикл. Библиотеку передаёт вызывающий: в пикере она уже в
   руке, в `renderExerciseCard` — тот же `getExerciseLibrary()`, что для бейджа мышц.
2. **Резолв как у бейджа, не exact-only.** Точное `name` / `nameRu`, нормализация
   `DB`→`dumbbell`, затем бидирекционный substring. Сидовые имена без текстового
   пересечения (`Butterfly Machine` ≠ `Pec Deck Fly`) — таблица оверрайдов на
   английское имя библиотеки, `nameRu` брать оттуда, не дублировать русские строки.
   Эталон покрытия — `test/muscle-badge.test.js`: каждый `PPL_GIO_PLAN` / `PPL_HYBRID_PLAN`
   обязан получить непустой `nameRu`.
3. **Пикер.** Подпись — `exerciseLabel`. `dataset.name` остаётся английским `ex.name`.
   Фильтр запроса включает `nameRu`. Мета `chest · barbell · compound` в этой карточке
   не переводить.
4. **Список тренировки.** Только `renderExerciseCard` (`js/workout.view/render.js:458`).
   Focus-оверлей, меню карточки, остров — не этот заход.

### Тесты — часть наряда

- `exerciseLabel` при `lang=en` возвращает вход как есть.
- При `lang=ru` — `nameRu` по точному имени и по сидовому (`Bench Press` → жим лёжа).
- Нет попадания в библиотеке → исходная строка, без броска.
- Пустой `nameRu` в записи библиотеки не подменяет имя пустой строкой.
- Гард сида: каждый лифт `PPL_GIO_PLAN` и `PPL_HYBRID_PLAN` резолвится в непустой `nameRu`.
- Источник `js/workout.view/modals.js`: при показе имени в пикере есть `exerciseLabel`
  (или `nameRu`), `dataset.name` по-прежнему из `ex.name`. Без этого исполнитель
  переведёт подпись и ключ одним движением.

### Полевой чек (в отчёт, не в тесты)

Safari, RU, чистые данные сайта. Пикер — поиск кириллицей. Старт Push — список на русском.
Профиль → язык EN — те же упражнения по-английски, веса на месте. Редактор плана после
тапа в пикере по-прежнему хранит английское имя.
