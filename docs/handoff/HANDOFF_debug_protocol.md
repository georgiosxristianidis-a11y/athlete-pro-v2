## 2. План debug (порядок, не меню)

1. **Intake (DBG-0 / INTAKE-1)** — собрать обязательные поля репорта. Нет полей → стоп.
2. **Карточка бага** — одна F-_/BUG-_ с симптомом; корень писать только после логов.
3. **Ветка** — `git fetch origin && git checkout -b claude/<id>-<slug> origin/main && npm run preflight`.
4. **Гипотезы (DBG-1)** — 3–5 точных причин; карта «гипотеза → точка лога».
5. **Инструментация** — NDJSON в `debug-af334e.log` через ingest; `#region agent log`; без секретов.
6. **Репро (DBG-2)** — очистить лог (`Delete` файла), один прогон пользователя, классификация гипотез.
7. **Фикс (DBG-3)** — только CONFIRMED; instrumentation оставить; `runId=post-fix`.
8. **Закрытие (DBG-4)** — подтверждение пользователя + логи → снять логи → тест-гард → сжатие карточки.

Правило проекта (verify-over-trust): «готово» без нулевого гейта и без ancestry = гипотеза.

## 3. Чек-лист debug (копипаст в сессию)

- [ ] **DBG-0** Репорт: симптом · шаги · env (устройство/браузер/версия/`CACHE_NAME`) · expected · actual · severity
- [ ] Ветка от `origin/main` + `npm run preflight` (exit 0)
- [ ] Ожидаемый код на месте (`grep`); нет → `git log origin/main -- <файл>`, не теория
- [ ] 3–5 гипотез с `hypothesisId`
- [ ] Логи вставлены (≤10), каждый мапит ≥1 гипотезу; `#region agent log`
- [ ] Лог-файл сессии очищен перед прогоном
- [ ] Пользователь воспроизвёл; в ответе есть `<reproduction_steps>`
- [ ] Каждая гипотеза: CONFIRMED / REJECTED / INCONCLUSIVE + цитата лога
- [ ] Отвергнутые гипотезы: **откатить** их код-изменения (не копить гарды)
- [ ] Фикс только по CONFIRMED; instrumentation жива
- [ ] Post-fix прогон; before/after по логам
- [ ] Пользователь подтвердил; логи сняты
- [ ] Тест-гард (mutation, не «чтение файла глазами»)
- [ ] `npm test` + `npm run lint`; счёт сюиты ≥ main (`git diff --diff-filter=A … origin/main -- test/`)
- [ ] Карточка сжата 3–5 строк; CHANGELOG; строка-роутер в `NEXT_SESSION.md` при необходимости
