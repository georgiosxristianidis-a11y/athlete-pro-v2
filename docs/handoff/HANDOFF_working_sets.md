## WSET-2 — значки (`js/shared/athlete-room.js:74`)

Лестница с прогрессом до следующей ступени:
- тоннаж за сессию 5/10/15/20 т (вместо `1T`, `tonnage >= 1000`);
- тоннаж за всё время 100/500/1000 т;
- тренировки 10/50/100/250;
- недельная серия: недели подряд с ≥2 тренировками, неделя с понедельника — вместо `_calcConsistency` (по факту «3 из 5 недель», неделя с четверга);
- число PR (`session.prs`) — отдельный значок; «Мастер жима» см. ниже.

Значки читают `getAll` → при флаге получат рабочий тоннаж сами. Дизайн карточки показать мокапом «было / A / B» до кода.

### Правки WSET-2 от Gio 11.10

- «7 дней подряд» — ОСТАЁТСЯ (решение Gio), недельная серия — рядом, не вместо.
- «Мастер жима» — лестница по `exrxTier({ lift: bench })` (`js/strength-engine.js:142`): Novice → Intermediate → Advanced → Elite по 1RM жима к весу тела, не счётчик push-сессий. Ориентир для мужчины ~90 кг: ~1.0× / 1.25× / 1.5× / 2.0× веса тела.
