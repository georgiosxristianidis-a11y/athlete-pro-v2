сборка могла поменять формат хуков/настроек.

**НЕ ТРОГАТЬ.** `DISABLE_AUTOUPDATER` в закоммиченном конфиге — решение Gio, не снимать без него.

## TOOL-3 (P2) — MCP playwright настроен, но мёртв

**ЦЕЛЬ.** Решить судьбу `mcpServers.playwright` из `~/.claude/settings.json`: за 58 дней **ноль вызовов**
`mcp__playwright__*`, и в сессии `/doctor` он вообще не поднялся — в списке инструментов его нет ни
резидентно, ни отложенно. То есть либо не запускается, либо не нужен.

**Сначала причина, потом фикс:** выяснить, падает он или просто не востребован. Не поднимается — чинить или
выключать; поднимается и не нужен — выключать.

```

```

**Ловушка.** Тумблер `/mcp disable` — **на текущий проект**, даже для user-scope сервера. Выключить везде =
повторить в TAXI и остальных чекаутах. `claude mcp remove` **не использовать**: она стирает конфиг и OAuth-токены
безвозвратно, обратно уже не включить.

**ГДЕ СТОП.** Либо сервер отвечает на пробный вызов, либо он в `disabledMcpServers` этого проекта.

**НЕ ТРОГАТЬ.** Встроенные серверы приложения (`Claude_Browser`, `ccd_session`, `visualize`, `terminal`,

## TOOL-4 (P2) — SessionStart-хук ест 7 секунд на каждом старте

**ЦЕЛЬ.** Ускорить `~/.claude/hooks/athlete-pro-guard.mjs` на событии SessionStart. Замеры за окно:
11 запусков, **медиана 7.3 с, максимум 12.8 с** — худший случай перевалил за порог 10 с, и это блокирующая
задержка перед каждым стартом и каждым resume. При `numStartups: 113` набегает.

**Варианты.** A (рек.) — кешировать результат preflight с коротким TTL, на resume отдавать кеш.
B — сузить матчер с `startup|resume|clear` до `startup`: resume не меняет состояние репо.
C — увести тяжёлую часть в асинхронный прогон, в хуке оставить чтение результата.

**Не путать с быстрыми.** Те же хуки на PreToolUse/PostToolUse `Edit|Write` — медиана 91 мс, максимум 134 мс,
вопросов нет. У PreToolUse ноль записей в транскриптах, но это ожидаемо: успешный хук с пустым выводом не пишется.

**ГДЕ СТОП.** Медиана SessionStart под 3 с, польза preflight не потеряна — FAIL защиты main по-прежнему виден на старте.

**НЕ ТРОГАТЬ.** Сам гард как гейт: он ловит реальные вещи (в сессии `/doctor` честно отдал FAIL по branch protection).
Цель — латентность, не отключение.

## TOOL-5 (P3) — закоммиченный allow-лист = пре-апрув произвольного кода

**ЦЕЛЬ.** Ревизия `permissions.allow` в закоммиченном `.claude/settings.json`. Четыре правила выглядят рутинно,
но по факту пре-апрувят выполнение чего угодно:

- `Bash(git *)` — `git -c core.pager=<cmd> log` запускает `<cmd>`; `git log --output=<file>` пишет файл
- `Bash(node *)` — любой скрипт
- `Bash(npx *)` — любой пакет из сети
- `Bash(npm run *)` — любой скрипт из `package.json`

Префиксные правила **не анализируют флаги**, в отличие от встроенных read-only валидаторов, которые принимают
только перечисленный безопасный набор. Правило `Bash(git *)` пропускает ровно те формы, что валидатор режет.

**Это осознанное решение Gio, а не находка.** Карточка — чтобы решение было принято ещё раз, зная цену, а не по инерции.
Вариант: заменить на набор точных правил под реально частые вызовы.

**ГДЕ СТОП.** Явный вердикт Gio: оставляем как есть (тогда карточку закрыть) или сужаем.

**НЕ ТРОГАТЬ.** `permissions.deny` — там `.env`, `*.pem`, `*.key`, `sudo`, `rm -rf`. Не ослаблять.

## Закрыто в этом заходе

- **Дефолтный режим разрешений** — `permissions.defaultMode: "auto"` уже стоит в `~/.claude/settings.json`,
  ни проектный, ни локальный конфиг его не перебивают. Здорово, действий нет.
- **Дедуп локальной памяти** — `CLAUDE.local.md` нет. `~/.claude/CLAUDE.md` (1098 симв.) пересекается с проектным
  `CLAUDE.md` в одном месте («рекомендация в самой строке» vs «Рекомендация, не меню»). **Не удалять:**
  пользовательский файл грузится во всех проектах, правило потерялось бы в TAXI и остальных. Противоречий,
  меняющих поведение, нет.
- **Обрезка `CLAUDE.md`** — резать нечего. 9032 симв., далеко под порогом предупреждения (~40 000); содержимое —
  гочи, запреты и указатели, то есть keep-категории. Макет каталогов подан как закон под `repo-hygiene.test.js`,
  а не как описание. Файл уже сторожит себя через `docs-budget.test.js`.
- **Миграция в ленивую загрузку** — мигрировать нечего: спеки уже в `.claude/rules/*.md` с `paths`, ритуал агента —
  в скилле `agent-brief`.
- **Пре-апрув частых отказов** — кандидатов нет. За окно 41 отказ, но **30 из них — `cd <путь> && <команда>`**,
  составные вызовы, которые нельзя пре-апрувить безопасно. Остальное отсеяно по существу: `gh api` (префиксное
  правило поймало бы POST/DELETE и GraphQL-мутации), `powershell`, `mkdir`, `chmod`, `git add`, `cat >`.
  Вывод для будущих заходов: **автомод блокирует не команды, а форму `cd X && ...`** — лечится не allow-листом,
  а тем, что команды гоняются без `cd`-префикса (абсолютные пути или отдельный вызов).
