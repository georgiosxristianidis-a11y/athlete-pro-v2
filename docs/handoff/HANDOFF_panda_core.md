## PANDA-A · Построчный вход бамбукового счёта — ✅ ЗАКРЫТА (1.25.63, PR#117)

Лесенка переехала с карточки на строки: Ты → Я → вердикт, шапка «СЧЁТ» стоит с первого кадра.

**Урок, ушедший в код.** В проекте **две несвязанные лесенки входа**, и `.summ-ledger` был подключён к обеим неправильно:

| Механизм | Где | Задержка |
|---|---|---|
| `.stagger-item` | `css/base.css:1246` | `nth-child`, 0.05–0.3с |
| `--stagger-i` | `css/summary.css:110` | `calc(var(--stagger-i) * 80ms + 100ms)`, **только** `.summ-island` |

Карточка несла `stagger-item` вместе с `--stagger-i:100` — переменную не читал никто, а читал бы, дала бы 8с задержки. **Заводя вход-анимацию, брать существующую лесенку, третью не плодить.**

`scale()` на строках счёта не применять: `.summ-ledger-val` набран `tabular-nums`, дробный масштаб мылит цифры субпиксельно на всё время анимации.

**Остаток — полевой чек Gio:** сводка при `panda-moods` + `fab-video`; вердикт приходит последним, шапка не мигает.

## PANDA-B · Реплики по архиву, а не по часам 🟠 (следующая)

- **ЦЕЛЬ:** приветствие на входе основано на реальной истории — «три недели без ног», «жим отстаёт», — а не только на простое.
- **Данные готовы:** `generateInsights()` (`js/insights.engine.js:26`) читает всю базу и отдаёт до 5 инсайтов (`kind`/`priority`/`title`/`body`). Локально, без сети — в airgap работает, приватность не трогаем.
- **Слой перевода обязателен:** движок отдаёт английские предложения, у панды потолок 5 слов. Чистая функция `insight.kind` → `{mood, key}` в `js/shared/panda-mood.js`, рядом с `entryGreeting`. Берём **один** инсайт с высшим приоритетом, не пять.
- **Приоритет (решение Gio):** время суток бьёт аналитику. `night_shift` / `early_bird` остаются первыми — это характер. Инсайт встаёт на место нынешней общей `ate_progress`: он обоснован лучше.
- **Доставка (решение Gio):** расширить `_pandaGreet` (`js/dashboard.js:297`). Троттлинг «раз в календарные сутки» через `panda-greeted-on`, тост и `emitMood` уже работают. Новых поверхностей ноль.
- **ГДЕ СТОП:** `panda-mood.js` + `dashboard.js` + ключи `mascot.*` в обе локали (`js/locale.store.js`).
- **НЕ ТРОГАТЬ:** формулы `insights.engine.js`; AI-коуча и заглушку `longTermStats` (отдельная работа); тесты `entryGreeting` дополнять, не переписывать.
- **DoD:** реплика меняется от состояния базы, а не только от часов; юнит на маппинг и на приоритет по образцу `test/panda-mood.test.js`.

## PANDA-C · Звук мимики 🟡 (ЗАБЛОКИРОВАНА: ждёт файлов Gio)

- **ЦЕЛЬ:** короткий звук в момент смены мимики. Не фон — обратная связь на действие.
- **Почему это вообще нужно:** в mood-режиме звук сломан by design, записано в шапке модуля (`js/shared/panda-mood.js:19`) — «в дорожке лежит озвучка целиком, и нарезка её рубит». `panda-moods` + звук = обрубок фразы в цикле 2.4с.
- **Ассеты за Gio.** Код пишется полностью, в `assets/` кладутся заглушки-тишина; Gio подменяет файлы, переписывать ничего не нужно. Формат: `.m4a` (AAC — тот же кодек, что в `panda-voice.mp4`, декодер гарантированно есть), моно, 48 кбит/с, ≲40 КБ суммарно.
- **Состав:** `chew` — хруст, `cheer` — короткий всплеск, `judge` — **тишина** (молчание сильнее реплики).
- **Триггер (решение Gio):** только на смене мимики. Не луп, не фон — час хруста за тренировку невыносим.
- **Точка врезки одна** — `set()` внутри `attachMood` (`js/shared/panda-mood.js:153`): через неё проходит каждая смена мимики. Второго места быть не должно.
- **Голос из mp4 в mood-режиме глушится совсем** — это и есть починка обрубка.
- **Дефолт OFF.** Существующие тумблеры (`js/claude.view.js:76`, `js/dashboard.js:29`) рулят и звуком мимик — один тумблер, не два.
- **Бюджет:** медиа исключено из прекеша гардом F-7 (`test/sw-media-budget.test.js`), потолок 1.5 МБ. Файлы качаются лениво. После добавления — `npm run build:sw`.
- **НЕ ТРОГАТЬ:** `bindPandaLifecycle` — обвес автоплея/батареи проверен, вторую копию не заводить.

## PANDA-D · Тряска и доворот на нажатии 🟢 (мелкая)

- **ЦЕЛЬ:** два микро-отклика на существующих токенах, ~8 строк CSS.

```css
.shake-once { animation: shake-once .4s var(--ease-spring); }
@keyframes shake-once {
  0%, 100% { transform: translateY(0) rotate(0); }
  25% { transform: translateY(-2px) rotate(-10deg); }
  50% { transform: translateY(0) rotate(10deg); }
  75% { transform: translateY(-2px) rotate(-10deg); }
}
.flip-180 { transition: transform .45s var(--ease-spring); }
.flip-180.is-on { transform: rotate(180deg); }
```

- **Применение:** доворот — на `week-pill` (`js/workout.view/render.js:229`), A↔B буквально переключение. Тряска — на панде в мимике `judge` (перебор отдыха).
- **Ловушка:** перезапуск анимации требует `void el.offsetWidth` между снятием и постановкой класса, иначе второе нажатие подряд ничего не проиграет.
- **⚠️ КОНФЛИКТ:** трогает `base.css` — не параллелить с TYPE-2 / SPACE-1 / NAV-BACK-1.
- **Происхождение — важно для ревью.** Gio приносил четыре React/framer-motion компонента. **Внедрять как есть отвергнуто:** ~90–120 КБ gzip рантайма (react + react-dom + framer-motion) плюс билд-пайплайн фронта, которого в проекте нет, при потолке прекеша 1.5 МБ. Три из четырёх построены на `whileHover` — **на телефоне hover не существует** (то же правило, что закрыло hover-подсказку в PCT-1). Два из четырёх уже написаны: морф иконки = `.morph-swap` (`css/base.css:360`), спиннер = `spin-gpu` (`css/base.css:370`). Осталось это.

## PANDA-E · SVG-маскот 🟠

- **ФАКТ, объясняющий карточку:** при выключенном `fab-video` (а он OFF по дефолту) у приложения **нет лица** — FAB рисует generic-кружок с восклицательным знаком (`js/claude.view.js:93`). Маскот существует только вместе с 327 КБ видео.
- **ЦЕЛЬ:** SVG-маскот, не зависящий ни от флага, ни от медиа.
- **Решение Gio по вариантам:** **цветной** на крупных поверхностях (пустой дашборд, сводка, FAB), **штриховой на `currentColor`** — в списках и хроме (16–24px). Геометрия у обоих одна, различается только заливка: передумаем — это подмена `fill`, не перерисовка.
- **Геометрия закрыта четырьмя итерациями с Gio, не переизобретать:**
  - Это **малая (красная) панда**. Круглая голова + круглые уши сверху = мышь или большая панда — отвергнуто дважды.
  - Череп — **широкий овал 48×37.5** в `viewBox 64`, не круг.
  - Уши **крупные, широкие у основания, скруглённые на конце**, наклон наружу. Не шпили.
  - Светлые брови — мелкие и высоко (`ry` ≈ 2.9, `cy` ≈ 24).
  - **Слёзных дорожек на щеках нет** — сняты Gio.
  - На 16px светлые метки морды выбрасываются: это не один файл, а два состояния силуэта.
- **Цвет:** требует 4 токена в `:root` — `--c-panda-fur` `#c2603d`, `--c-panda-fur-d` `#8f3f2a`, `--c-panda-face` `#f2e4d4`, `--c-panda-ink` `#2a1c18`. Дизайн-лок Cool Steel — про геометрию, не про цвет, и `--c-accent` в проекте прямо оставлен «для празднования», так что рыжий закон не нарушает.
- **НЕ ТРОГАТЬ:** видео-путь (`panda-video.js`) — SVG живёт рядом, не вместо.
