## PANDA-A · Построчный вход бамбукового счёта — ✅ ЗАКРЫТА (1.25.63, PR#117)

**Урок, ушедший в код.** В проекте **две несвязанные лесенки входа**, и `.summ-ledger` был подключён к обеим неправильно:

| `.stagger-item` | `css/base.css:1246` | `nth-child`, 0.05–0.3с |

`scale()` на строках счёта не применять: `.summ-ledger-val` набран `tabular-nums`, дробный масштаб мылит цифры субпиксельно на всё время анимации.

## Почему линия не вливается — доказано прогоном, не чтением

- **Утечка BYOK-ключа.** `gemini-key`/`anthropic-key` живут в `DB.Settings`, а `settings` стоит
  в `SYNC_STORES` (`js/sync.js:6`). Сквозной PoC: ключ уехал открытым текстом в `data/sync.json`
  и вернулся анониму по `GET /api/sync/pull?since=0`.
- **Аутентификации у `/api/sync/*` нет вообще**, хранилище одно на всех, разреза по пользователю нет.
- **Airgap сломан:** `runSync()` безусловен (2с после старта + каждые 60с), `getPrivacyMode()`
  не спрашивается. В браузере без действий пользователя ушло 3 workouts, 2 bodyMetrics, 17 settings.
- **Регресс, а не фича:** в `main` `SyncManager` — 415 строк на Supabase, с аутентификацией
  (`supabase.auth.getUser()`) и разрезом по пользователю. Ветка заменила его самописным файловым
  движком на 211 строк без аутентификации. Плюс снесла экспорт, оставив 4 живых импорта
  (`js/db/core.js:246`, `js/profile.js:110/697/712`) — Профиль показывает вечный «offline»,
  вход и выход из аккаунта падают `TypeError`.
- **HLC отравляется необратимо:** запись с `hlc.l = 8640000000000000` уводит часы на 273 728 лет
  вперёд (`stateL` только растёт) и навсегда выигрывает LWW. Верхней границы дрейфа нет.
- **Тихая потеря данных:** `id: "__proto__"` даёт HTTP 200 и `merged: 1` без записи в базу.
  Клиент двигает `lastSync` — запись исчезает навсегда.
- **Три ослабления периметра в одном коммите** `6d7074e` («chore: P.A.N.D.A Core ui polish and tts
  fixes»): лимит тела `100kb → 10mb` глобально, `vercel.live` в `script-src`, и whitelist

  `backdrop-filter`. Урок: **дифф `test/` при аудите читать раньше диффа кода.**

  вопроса «эндпоинт защищён?» в задании не было, и никто его не задал. Это правило «зелёный гейт
  отвечает только на свой вопрос», поднявшееся на уровень всей проверки.

Наружу ничего не ушло: ветки нет на origin, коммитов нет в `main`, деплой идёт с `main`.
