## Решения Gio (01.11)

- **Главная цифра — «Мой максимум»**: реально поднятый вес лучшего подхода (вес × повторы). 1RM — доп. строкой в конце.
  Нормы уровня (ExRx, DOTS) считаются по 1RM, но на экране максимум первым.
- **Уровень — по своим упражнениям**: жим — ExRx; тренажёры — рост от старта; DOTS только при приседе и становой
  со штангой, иначе подпись «нужны присед и становая», не «Новичок».
- **Хак-присед и присед в тренажёре** — семейство «присед», вариант «тренажёр»: графики, мышцы, ромб, рост; в DOTS нет.
- **Жим гантелей сидя** — на оси OHP ромба как аналог; в нормах ExRx для штанги нет.
- **Вес тренажёров ног** — только блины, без платформы. Брусья: вес = отягощение (0 = свой вес); тренажёр dips: вес = стек.
- **Короткая сессия (<60 мин)** — тест ИЛИ тренировка задним числом. Удалять только тест (нулевые веса, всё skipped),
  списком на утверждение Gio. Сессии импорта (`imp-`, `duration: 0`) фильтр по длительности не трогает.
