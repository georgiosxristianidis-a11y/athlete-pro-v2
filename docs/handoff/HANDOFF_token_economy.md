## Допущения, которые надо атаковать (не находки)

- **«10 токенов на строку кода»** → отсюда оценка «выход к осевшему коду 44:1». Порядок устойчив, точность нет.
- **Связь `CLAUDE_AUTOCOMPACT_PCT_OVERRIDE: 50` с 32,6% на cache-write не доказана** — только кандидат на A/B. В TOK-6 это эксперимент, не диагноз.
- Деньги — list-цена по прайсу Anthropic, **не счёт**: подписка списывает иначе. Метрика для сравнения операций между собой.

## Ловушки

- `npm run tokens` читает `~/.claude/projects` — **вне репо и вне git**. Цифры машинно-локальные: у другого агента на другой машине они свои.
- Скрипт видит и текущую сессию: два прогона подряд дают разные числа. Для дельты «до/после» мерить в одинаковой фазе.
- Замер по slug каталога. Ворктри проекта попадают автоматически, посторонний проект с похожим именем — тоже.
