## PERF-0 — честный замер

**ЦЕЛЬ.** Число `lhci` можно сравнивать между прогонами и с продом.

**ГДЕ СТОП.** `scripts/lighthouse.js`: (1) `mkdirSync(test-results, {recursive})` — в свежем
worktree скрипт падает на `--output-path cannot be written`; (2) медиана трёх прогонов вместо
одного, в выводе — разброс; (3) `--url <адрес>` — те же три прогона по проду; (4) первым
коммитом в карточку записан разброс на 3 прогонах local и prod — без него «81 против 92» не
отличить от шума машины. Порог **не менять**.

**ФАЙЛЫ.** `scripts/lighthouse.js`. **ГЕЙТ.** `npm run lhci` из worktree, `npm test`.
**НЕ ТРОГАТЬ.** Пороги, `test/`, код приложения. Отчёты `test-results/` не коммитить.

## PERF-1 — LCP: постер FAB виден в HTML

**ЦЕЛЬ.** LCP на проде ≤2.5 с (сейчас 3.1), локально ниже 3.5 с.

**ГДЕ СТОП.** Запрос постера стартует из разбора HTML, а не после исполнения JS. Варианты:
**A (рек.)** — `<link rel="preload" as="image" href="assets/panda-poster.jpg" fetchpriority="high">`
в `index.html`, адрес совпадает с `PANDA_POSTER_SRC` (`js/shared/panda-video.js:10`, относительный) побайтно (иначе двойная загрузка);
B — статичный `<img>` постера в оболочке FAB, JS его гидрирует. A — одна строка и не трогает
разметку; B — только если A не дала цели: он лезет в `claude.view.js`/`dashboard.js`, где
BOOT-TRIM уже ловил гонку `async`-пустого состояния.
Перемерить: 3 прогона prod, LCP-элемент в отчёте может **смениться** (следующий по площади) —
записать какой, это меняет постановку `PERF-2`.

**ФАЙЛЫ.** `index.html`; при B ещё `js/claude.view.js`. **ГЕЙТ.** `npm run build:sw`
(прекеш строится по `modulepreload` — тег `as="image"` в него попасть не должен, проверить
`test/boot-graph.test.js`), `npm test`, бамп версии (правка `index.html` затрагивает `js/`-гейт
только через `build:sw`; сверить `version-bump-required`).
**НЕ ТРОГАТЬ.** Флаг `fab-video`, логику `initPandaVideo`, `assets/panda-voice.mp4`.

## PERF-2 — постер по размеру показа

**ЦЕЛЬ.** Постер ≈ 128×128 (62 px × 2x DPR), ≤4 КБ вместо 17.8 КБ; `image-delivery` чист.

**ГДЕ СТОП.** Новый файл постера (jpg или webp — webp только если `sw.js`/`server.js` отдают
верный `Content-Type`, проверить `curl -I`); `PANDA_POSTER_SRC` и запись в прекеше обновлены;
на всех местах показа постер не мылится (FAB 62 px, `dashboard.js:362` — пустое состояние Home,
там панда крупнее: **сперва найти все места и их размер**, если Home показывает 480 px —
нужны два файла, а не один). Тест на вес файла постера (потолок в байтах).

**ФАЙЛЫ.** `assets/panda-poster*`, `js/shared/` (константа), `sw.js` (только `build:sw`).
**НЕ ТРОГАТЬ.** Видео, маскот-скины (`PANDA-SKINS`, заморожена).

## PERF-3 — `robots.txt`

**ЦЕЛЬ.** `seo` 92 → 100, строка `robots-txt` в отчёте чиста.

**ГДЕ СТОП.** `GET /robots.txt` → 200 `text/plain`, содержимое `User-agent: *` /
`Allow: /` / `Disallow: /api/`. `index.html` уже несёт `robots: index,follow` и `canonical`, то
есть индексация задумана открытой — **подтвердить у Gio до правки**, если нет — `Disallow: /`.
**Мины:** (1) файл в корне красит `test/repo-hygiene.test.js` (в корне только entry-точки) —
отдавать **маршрутом в `server.js`** строкой, файла нет; иначе он ещё и не попадёт в бандл без
`includeFiles` (урок `legal/`); (2) `sw.js` не должен отдавать на `/robots.txt` навигационный
фолбэк-шелл — проверить обработчик `fetch`. Тест: `startServer(0)`, статус, тип, тело.

**ФАЙЛЫ.** `server.js`, новый тест. **НЕ ТРОГАТЬ.** `legal/**`, CSP.

## PERF-4 — блокирующий CSS: `base.css` и `dashboard.css`

**ЦЕЛЬ.** FCP локально ≤2.0 с, `render-blocking-insight` без `base.css`.

**ГДЕ СТОП.** `base.css` 24 КБ, на первом кадре не используется 82% (19 КБ), по замеру держит
рендер 610 мс, `dashboard.css` — 310 мс. Резать на критичный минимум (токены `:root`, оболочка,
Home, nav) + остальное через уже существующий механизм `media="print" data-lazy` →
`js/boot.js`. Инварианты: токены `:root` — только в критичной части (`design.md`); CLS остаётся
≤0.01 (сейчас 0.001 — потолок, терять нельзя); `test/design-tokens.test.js`,
`test/boot-graph.test.js` зелёные.
**Самая рискованная карточка линии — брать после PERF-1..3 и перемера:** если FCP на проде уже
≤1.8 с, карточка не нужна, закрыть строкой «замер, не берём».

**ФАЙЛЫ.** `css/base.css`, `index.html`, `js/boot.js`. **НЕ ТРОГАТЬ.**
`js/theme-boot.js` — синхронный по замыслу (анти-вспышка темы); инлайн-скрипт упрётся в CSP.
Значения цветов и типографики — только токены, сырьё запрещено.

## PERF-5 — срок кэша `/assets`

**ЦЕЛЬ.** Повторный заход не тянет 329 КБ видео и постер заново раз в час.

**ГДЕ СТОП.** `server.js:118` — `maxAge: '1h'`. **A (рек.)** — `public, max-age=86400,
stale-while-revalidate=604800`: файлы не хешированы, но SW бьёт свою копию через `CACHE_NAME`,
а подмена ассета без переименования — редкость; B — хешировать имена (дороже, трогает прекеш).
**Честно: на холодном прогоне Lighthouse балл не изменится** (кэша нет), выигрыш — возвращающийся
пользователь. Проверка — `curl -I` заголовков локально и на проде, тест на заголовок.

**ФАЙЛЫ.** `server.js`. **НЕ ТРОГАТЬ.** Политику `.js`/`.css`/`.html` (`no-cache`/`no-store`) —
за ней стоит полевой случай залипшей 1.24.1, комментарий в `server.js:121-126`.

**ФАЙЛЫ.** по итогам замера. **НЕ ТРОГАТЬ.** Логику мимики (`PANDA-*`).

## PERF-7 — минификация JS/CSS — **ЗАМОРОЖЕНА до вердикта Gio**

Отчёт: `unminified-javascript` 34–47 КБ (`workout.store.js`, `panda-mood.js`, `dashboard.js` …),
`unminified-css` 15–19 КБ. Веса в балле не имеет; после gzip выигрыш втрое меньше названного.
Цена — **первый шаг сборки в проекте без сборки**: Vanilla JS без бандлера, прекеш по
`modulepreload`, гарды по исходникам, `sw.js` по `CACHE_NAME`. Рекомендация — **не брать**, пока
`PERF-1..4` не отработали и цель 90 не достигнута другим путём; если всё же нужна — отдельное
решение Gio и отдельная карточка про место минификации (шаг деплоя Vercel, а не коммит).
