> Заведён 2026-09-24 по решению Gio. **Цель:** `performance`, `accessibility`, `best-practices`,
> `seo` — каждая ≥90 на `npm run lhci` (мобильный профиль) и на проде. Порог `performance`

> Порядок — по цене для балла, не по трудоёмкости. Блокером `LAUNCH-10` линия **не** является:

## PERF-9c — первый визит не грузит остров и панду, пока идёт онбординг

**Брать после PERF-9 и перемера на проде.** Нужна, только если медиана perf <98.

**ЦЕЛЬ.** На холодном старте с онбордингом канал отдан `onboarding.js`: `dynamic-island.js/.css`,
`claude.view.js` (+`panda-mood.js`), `claude.css` стартуют после первого кадра онбординга, а не
параллельно ему. Замер 25.11: `onboarding.js` 8 KiB грузится 560 мс из-за конкуренции.

**ГДЕ СТОП.** (1) baseline: в водопаде холодного прогона эти модули стартуют до конца
`onboarding.js`; (2) после правки — после LCP, `onboarding.js` грузится быстрее (дельта в одной
сессии, MEASURE-1); (3) возвращающийся пользователь (сид) — остров и FAB появляются как раньше,
его LCP не хуже. За флагом `onboarding-defer-chrome` (дефолт OFF). Ждём ≈−0.2…0.3 с LCP — оценка,
не замер.

**ФАЙЛЫ.** `js/app.js`, `js/flags.js`, тест, версия. **НЕ ТРОГАТЬ.** Порядок
`needsOnboarding → Dashboard.load`, бут-цепочку `openDB → … → loadHapticPref`, логику острова.

## PERF-5 — срок кэша `/assets`

**ЦЕЛЬ.** Повторный заход не тянет 329 КБ видео и постер заново раз в час.

**ГДЕ СТОП.** `server.js:118` — `maxAge: '1h'`. **A (рек.)** — `public, max-age=86400,
stale-while-revalidate=604800`: файлы не хешированы, но SW бьёт свою копию через `CACHE_NAME`,
а подмена ассета без переименования — редкость; B — хешировать имена (дороже, трогает прекеш).
**Честно: на холодном прогоне Lighthouse балл не изменится** (кэша нет), выигрыш — возвращающийся
пользователь. Проверка — `curl -I` заголовков локально и на проде, тест на заголовок.

**ФАЙЛЫ.** `server.js`. **НЕ ТРОГАТЬ.** Политику `.js`/`.css`/`.html` (`no-cache`/`no-store`) —
за ней стоит полевой случай залипшей 1.24.1, комментарий в `server.js:121-126`.

## SW-CACHE — тёплый старт без сети (вне балла, про зал) — сделано за флагом, ждёт поля Gio

Сделано в 1.27.160 (`claude/sw-cache-warm-start`): флаг `sw-cache-first`, дефолт OFF — прод без
изменений. С флагом ON повторный визит не ходит в сеть за кодом (68 → 0 запросов на сервер);
метрика `scripts/profile.mjs` починена — прокси считает запросы на стороне сервера. Детали и
дельты — `CHANGELOG.md`. Дальше: поле Gio на Android (`Flags.setFlag('sw-cache-first', true)`,
слабый Wi-Fi — до Home без ожидания сети; деплой — обновление за один перезапуск), затем дефолт
ON отдельным PR.

| Совет | Причина отказа (проверено по коду 1.27.156) |
