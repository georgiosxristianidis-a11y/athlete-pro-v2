## ANL-1 · Volume Trend на главной: 7/30/90 + неоновое дно

Где: `js/dashboard.js` `renderSparkline()` (~518), `setVolumeDays()` (~1040), `js/shared/sparkline.js`, `css/base.css .spark-stroke`.

Причина (подтверждено в превью на сиде 3 трен./нед): точка = день; у каждой из 3 PPL-линий ~6 нулей из 7 —
нули всех трёх лежат на `y = height - padding` друг на друге, и `.spark-stroke` даёт им зелёный `drop-shadow`
→ сплошная неоновая полоса по дну + гребёнка пиков. Пустое окно (`globalMax === 0`) рисует ту же полосу из `[0,0,0,0]`.

**ЦЕЛЬ (решение Gio — «шаг по окну», «окно к окну»):**
- 7 → столбики по дням (PPL-цвет столбика, как `cv-volume` в аналитике); 30 → недели (5 точек); 90 → недели (13 точек). Одна суммарная линия, без нулевых провалов.
- Пилюля %: окно против предыдущего равного окна, подпись «к пред. 30д». Прошлое окно пустое → пилюлю скрыть (сейчас фальшивые +100%).
- Пустое окно → текст `dash.no_data`, не плоская линия.

Попутные баги того же места: при `globalMax === 0` ранний `return` не обновляет `#spark-total` — остаётся сумма прошлого окна;
цвета пилюли — сырой `rgba(...)` (закон токенов); кнопки 36×32 < 44 тап-зоны.

**ГДЕ СТОП:** главная. Шторка периода Аналитики (`analytics.view.js _openPeriodSheet`, отдельный ключ `ap-analytics-period`) — не трогать; объединение двух настроек периода — отдельной карточкой, если Gio захочет.
**ГЕЙТ:** unit на агрегацию (неделя/день, окно к окну, пустое прошлое окно) + скрин 7/30/90 в превью.

## ANL-3 · Индекс силы: цепной по e1RM

Где: `js/analytics.strength-curves.js` `buildSeries()` (25), `strengthIndex()` (237), `strengthIndexPlot()` (346), подпись `analytics.index_cap`.

Найдено (числа — сид в превью, 5 мес.):
| # | Дефект | Эффект |
|---|---|---|
| 1 | Лифт входит в среднее с ratio 1.0 в месяц появления | новое упражнение роняет индекс без потери силы: 152 → 139 |
| 2 | Арифметическое среднее отношений | завышает: +50% и −33% дают +8.5% вместо 0 |
| 3 | Метрика = макс. рабочий вес | 80×5 → 80×10 = 0% роста |
| 4 | Мини-спарк в hero ставит точки по индексу, график в шторке — по времени | пропущенный месяц выглядит по-разному |
| 5 | Ключ серии — точное `ex.name`, история упражнения нормализует регистр и `alias` | одна тяга бьётся на две серии |

**ЦЕЛЬ (решение Gio):** месячное значение лифта = макс. `estimate1RM` (`js/strength-engine.js`) по поднятым подходам;
индекс(m) = индекс(m−1) × geomean(e1RM(m)/e1RM(m−1)) только по лифтам, что есть в обоих месяцах; старт 100. Пропуск месяца у лифта — сравнивать с последним виденным. Подпись `index_cap` переписать («средний рост силы с начала», ru/en).
Кривые прогресса (карточки лифтов) остаются по рабочему весу — их не трогать.
**ГЕЙТ:** unit — (а) новый лифт в середине не двигает индекс, (б) +50%/−33% → 100, (в) рост повторов при том же весе поднимает индекс. Добавленные тесты в `test/` читать раньше кода.
