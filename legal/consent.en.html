Consent to data processing

By using Athlete Pro you agree to processing as described in the privacy policy and below. This is a draft for the document set; the publisher confirms whether the wording is legally fit (georgiosxristianidis@gmail.com).

1. What happens with no extra toggle

For the log to work, the app writes the IndexedDB database athlete-pro (seven stores) and service keys in localStorage on this device. A new install defaults to airgap: workouts, profile and keys are not sent anywhere. Fonts and the shell load from the same origin — no Google Fonts.

Opening any page, including this one, is an ordinary request to Vercel hosting (URL, IP, User-Agent). That is how the site is delivered, not a separate analytics product.

2. What needs an explicit action

  • Cloud. Cloud or Anonymous mode when Supabase is configured: an anonymous session and a replica of six stores (everything except the local events log). Secrets and ap-* keys are not in that replica.
  • AI coach. The toggle in Privacy (unavailable in airgap). Then a compressed workout context, a profile slice (name, age, sex, goal) and the chat text go to our server and on to Anthropic or Google. Your own API key, if you pasted one, rides on the same request.
  • Usage counter. The usage-stats flag is on. Three aggregates (app open, saved workout, coach question) go to Vercel Web Analytics only when the other gates are open: no DNT/GPC, no self-exclusion, the Privacy toggle not off, and a Vercel production host.

3. How to withdraw

Switch to airgap — sync and AI network calls stop, and the AI toggle is cleared. Turn the AI coach off on its own if you still want the cloud. Export JSON, then delete local data in the passport or clear the site’s data in the browser. The in-app button does not erase the cloud replica: write to the publisher for that. Limits of the delete button are in the privacy policy.

4. Age

This consent is given by someone 16 or older. If you are younger, use the service only with a guardian’s consent.
